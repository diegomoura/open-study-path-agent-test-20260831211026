# TOPIC-006 — Fluxo de feature branch e pull requests

## O que você vai aprender

Você vai conseguir trabalhar num fluxo de feature branch (uma branch dedicada por tarefa), manter sua branch atualizada com a principal usando merge ou rebase, e abrir pull requests bem descritos no GitHub.

## Por que isso importa para você

Você já abriu PRs pequenos na sua própria branch, mas nunca dentro de um fluxo de time com branches de feature — que é exatamente o do seu novo emprego. Esta etapa usa o que você já sabe sobre merge (Aula 03) e rebase (Aula 04) para manter sua branch atualizada dentro desse fluxo.

## O que você já precisa saber

- **Aula 03 — Merge** e **Aula 04 — Rebase:** você precisa já conseguir executar as duas operações, porque manter uma feature branch atualizada com a principal usa exatamente uma delas.

## Seu plano para esta etapa

- [ ] Recuperar o que já sabe sobre merge e rebase (10 min)
- [ ] Estudar o conceito de feature branch e branch protegida (15 min)
- [ ] Praticar manter uma feature branch atualizada com a main (20 min)
- [ ] Abrir um pull request com boa descrição (20 min)

## Aula

Esta aula será preparada automaticamente quando você concluir os pré-requisitos desta etapa (Aula 03 e Aula 04). Você não precisa pedir a geração manualmente.

## Prática

A prática guiada e a prática independente vão ficar dentro da aula, incluindo a criação de uma feature branch e a abertura de um pull request real.

## O que você vai produzir

Uma feature branch mantida atualizada com a main (por merge ou rebase) e um pull request aberto com uma descrição clara do que foi feito e por quê.

## Como mostrar o que aprendeu

A evidência esperada é o link do pull request aberto, acompanhado de uma explicação de qual estratégia (merge ou rebase) você usou para atualizar a branch e por quê.

## Para concluir esta etapa

- [ ] Criar e trabalhar em uma feature branch dedicada.
- [ ] Manter a branch atualizada com a main usando merge ou rebase.
- [ ] Abrir um pull request com descrição clara.
- [ ] Explicar a diferença entre atualizar por merge e por rebase.
- [ ] Alcançar a pontuação mínima da avaliação sem um equívoco crítico.
