# Integrações ativas

A trilha está organizada nas Issues deste repositório GitHub (https://github.com/diegomoura/open-study-path-agent-test-20260831211026).

- Cada aula é uma issue; use os labels `study:*` para ver em que estado ela está.
- Nenhum lembrete adicional está ativo.
- Rotina de estudo: modo **none** (sem calendário fixo nem lembretes externos configurados) -- você avança conforme sua disponibilidade.
- O GitHub continua sendo a fonte de verdade para conteúdo, avaliações e progresso.
